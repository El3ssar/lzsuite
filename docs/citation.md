# Citation and attribution

lzsuite is an MIT-licensed wrapper around the numerical engine
[lzcomplexity](https://github.com/pleros-ai/lzcomplexity). The wrapper provides
array handling, discretization, shared category encodings, and process-level
execution. Scientific estimator implementation and its references belong to
the underlying engine.

## Cite the software you used

- [lzsuite on Zenodo, all versions](https://doi.org/10.5281/zenodo.23858269)
- [lzsuite 0.1.0 archive](https://doi.org/10.5281/zenodo.23858270)
- [lzsuite on PyPI](https://pypi.org/project/lzsuite/)
- [Machine-readable CITATION.cff](https://github.com/El3ssar/lzsuite/blob/main/CITATION.cff)

For a reproducible study, cite the version DOI for the exact release and record
the lzcomplexity version as well. The concept DOI identifies the project across
versions. Published GitHub releases are archived automatically; a source version
bump by itself does not create a DOI.

## Underlying engine

See lzcomplexity's [authors and citation](https://pleros-ai.github.io/lzcomplexity/project/authors/)
and [research references](https://pleros-ai.github.io/lzcomplexity/project/references/)
for engine authorship and the relevant scientific sources. Do not attribute
estimator development to the wrapper alone.

## Figures

All gallery observations are synthetic and generated by the checked-in plotting
