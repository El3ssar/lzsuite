# Figure generation

The gallery is generated by a checked-in Python script using NumPy, Matplotlib,
and lzsuite calls.

## Regenerate

From a source checkout:

```sh
uv sync --locked --group docs
uv run --locked --group docs python scripts/generate_docs_figures.py
```

Or run `make docs-figures`. Each figure is exported as SVG and PNG in light and dark palettes.
Dark exports are stored in `assets/figures/dark/`; the displayed figure follows
the site theme through CSS. SVG exports
retain text and can be used in a presentation or scientific document without
rasterizing axes and labels.

## Reproduction settings

The generator uses a NumPy random seed of **1729** and one sequential RNG stream.
Independent cells using the same seed but consuming a different number of draws
will not reproduce each figure's exact realization. Use the full script for that.

The comparison panel uses 8192 symbols per sequence and a fixed E cap of 6.
Figure provenance records Python and package versions, the seed, settings,
measurements, distance matrices, and serial/parallel maximum difference.

Matplotlib uses a noninteractive backend and bundled DejaVu fonts. SVG timestamps
are omitted and hash IDs use a fixed salt. Rendering can still vary across
Matplotlib or font-engine versions; use the lockfile to reproduce the development
environment. The gallery does not make hardware-specific timing claims.

## Check the site

```sh
make docs             # regenerate figures, check docstrings, build strictly
make docs-serve       # preview locally, with live reload
```

A documentation CI job repeats the build, executes the docstring examples, and
checks local links, generated API entries, images, and accessible text. The
GitHub Pages workflow publishes from `main` after that validation.
