# Distance functions

The same function supports all-pairs comparison within one collection and
corresponding-pair comparison between two collections.

::: lzsuite.distance

## lzsuite.nid

`nid` is an alias for `distance`, with the same signature, behavior, and return
types. It is not a second estimator. See the generated reference above for every
parameter and the [distance guide](../guide/distances.md) for examples.
